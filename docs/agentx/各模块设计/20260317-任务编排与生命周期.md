# 任务编排与生命周期设计

## 1. 核心问题

- OA 如何创建和投递任务到 OpenFang
- TaskRun 的状态如何在双方同步
- 任务失败、超时、取消如何处理
- 长任务的中断与恢复

## 2. 任务模型

### 2.1 任务对象

**TaskBinding（任务绑定）**：
```sql
CREATE TABLE agentx_task_binding (
    id BIGINT PRIMARY KEY,
    tenant_id BIGINT NOT NULL,
    task_id VARCHAR(64) NOT NULL COMMENT 'OA 侧任务 ID',
    task_run_id VARCHAR(64) COMMENT 'OpenFang TaskRun ID',
    agent_id VARCHAR(64) NOT NULL,
    user_id BIGINT NOT NULL COMMENT '发起用户',
    business_type VARCHAR(32) COMMENT '业务类型：LEAVE, EXPENSE, CRM',
    business_id VARCHAR(64) COMMENT '业务单据 ID',
    status VARCHAR(16) NOT NULL COMMENT 'PENDING, RUNNING, COMPLETED, FAILED, CANCELLED',
    priority INT DEFAULT 5,
    context JSON COMMENT '业务上下文',
    result JSON COMMENT '执行结果',
    error_message TEXT,
    created_time DATETIME NOT NULL,
    started_time DATETIME,
    completed_time DATETIME,
    INDEX idx_tenant_status (tenant_id, status),
    INDEX idx_agent (agent_id),
    INDEX idx_business (business_type, business_id)
);
```

### 2.2 任务状态

```
PENDING    → 已创建，等待投递
QUEUED     → 已投递到 OpenFang，排队中
RUNNING    → 执行中
BLOCKED    → 阻塞（等待审批）
COMPLETED  → 成功完成
FAILED     → 失败
CANCELLED  → 已取消
TIMEOUT    → 超时
```

**状态转换**：
```
PENDING → QUEUED → RUNNING → COMPLETED
                  ↓
                BLOCKED → RUNNING
                  ↓
                FAILED / CANCELLED / TIMEOUT
```

## 3. 任务投递

### 3.1 投递流程

```java
public TaskBinding submitTask(TaskRequest request) {
    // 1. 创建任务绑定
    TaskBinding binding = new TaskBinding();
    binding.setTaskId(generateTaskId());
    binding.setTenantId(getCurrentTenantId());
    binding.setAgentId(request.getAgentId());
    binding.setUserId(request.getUserId());
    binding.setStatus(TaskStatus.PENDING);
    taskBindingMapper.insert(binding);

    // 2. 组装业务上下文
    BusinessContext context = contextAssembler.assemble(request);

    // 3. 计算权限范围
    ExecutionContext execCtx = authService.buildExecutionContext(
        request.getAgentId(),
        request.getUserId()
    );

    // 4. 调用 OpenFang 创建 TaskRun
    try {
        TaskRunResponse response = openFangClient.createTaskRun(
            request.getAgentId(),
            request.getInstruction(),
            context,
            execCtx
        );

        // 5. 更新绑定
        binding.setTaskRunId(response.getTaskRunId());
        binding.setStatus(TaskStatus.QUEUED);
        taskBindingMapper.updateById(binding);

        return binding;
    } catch (Exception e) {
        binding.setStatus(TaskStatus.FAILED);
        binding.setErrorMessage(e.getMessage());
        taskBindingMapper.updateById(binding);
        throw e;
    }
}
```

## 4. 状态同步

### 4.1 同步模式

**推送模式（OpenFang → OA）**：
```
POST /api/agentx/tasks/{taskId}/status

Request:
{
  "task_run_id": "tr_abc123",
  "status": "running",
  "progress": 30,
  "current_step": "查询待办任务",
  "updated_at": "2026-03-17T02:31:00Z"
}
```

**轮询模式（OA → OpenFang）**：
```
GET /api/tenants/{tenantId}/tasks/{taskRunId}

Response:
{
  "task_run_id": "tr_abc123",
  "status": "running",
  "progress": 30,
  "steps": [
    {"step": "查询待办", "status": "completed"},
    {"step": "分析规则", "status": "running"}
  ]
}
```

**推荐策略**：
- 状态变更：推送（实时性）
- 进度更新：推送（每 10% 或关键步骤）
- 详细查询：轮询（按需）

### 4.2 事件通知

**OpenFang 事件**：
```java
public enum TaskEvent {
    STARTED,        // 任务开始
    PROGRESS,       // 进度更新
    BLOCKED,        // 阻塞（等待审批）
    RESUMED,        // 恢复执行
    COMPLETED,      // 完成
    FAILED,         // 失败
    CANCELLED       // 取消
}
```

**OA 事件处理**：
```java
@EventListener
public void handleTaskEvent(TaskEvent event) {
    TaskBinding binding = taskBindingMapper.selectByTaskRunId(event.getTaskRunId());

    switch (event.getType()) {
        case STARTED:
            binding.setStatus(TaskStatus.RUNNING);
            binding.setStartedTime(event.getTimestamp());
            break;
        case BLOCKED:
            binding.setStatus(TaskStatus.BLOCKED);
            // 创建审批请求
            approvalBridge.createApproval(binding, event.getBlockReason());
            break;
        case COMPLETED:
            binding.setStatus(TaskStatus.COMPLETED);
            binding.setResult(event.getResult());
            binding.setCompletedTime(event.getTimestamp());
            break;
        // ...
    }

    taskBindingMapper.updateById(binding);
}
```

## 5. 任务控制

### 5.1 取消任务

```java
public void cancelTask(String taskId) {
    TaskBinding binding = taskBindingMapper.selectByTaskId(taskId);

    // 调用 OpenFang 取消
    openFangClient.cancelTaskRun(binding.getTaskRunId());

    // 更新状态
    binding.setStatus(TaskStatus.CANCELLED);
    taskBindingMapper.updateById(binding);
}
```

**OpenFang API**：
```
POST /api/tenants/{tenantId}/tasks/{taskRunId}/cancel

Response:
{
  "cancelled": true,
  "cleanup_status": "pending"
}
```

### 5.2 超时处理

```java
@Scheduled(fixedDelay = 60000) // 每分钟
public void checkTimeout() {
    List<TaskBinding> runningTasks = taskBindingMapper.selectRunning();

    for (TaskBinding task : runningTasks) {
        Duration elapsed = Duration.between(task.getStartedTime(), now());
        if (elapsed.compareTo(task.getTimeout()) > 0) {
            // 超时，取消任务
            cancelTask(task.getTaskId());
            task.setStatus(TaskStatus.TIMEOUT);
            taskBindingMapper.updateById(task);

            // 通知用户
            notifyUser(task.getUserId(), "任务超时：" + task.getTaskId());
        }
    }
}
```

### 5.3 重试机制

```java
public void retryTask(String taskId) {
    TaskBinding oldBinding = taskBindingMapper.selectByTaskId(taskId);

    // 创建新任务
    TaskRequest request = TaskRequest.from(oldBinding);
    TaskBinding newBinding = submitTask(request);

    // 关联重试关系
    newBinding.setRetryOfTaskId(taskId);
    taskBindingMapper.updateById(newBinding);
}
```

## 7. 任务查询

### 7.1 查询接口

```java
// 查询用户的任务
public Page<TaskBinding> queryUserTasks(Long userId, TaskQuery query) {
    return taskBindingMapper.selectPage(
        query.toPage(),
        Wrappers.<TaskBinding>lambdaQuery()
            .eq(TaskBinding::getUserId, userId)
            .eq(query.getStatus() != null, TaskBinding::getStatus, query.getStatus())
            .orderByDesc(TaskBinding::getCreatedTime)
    );
}

// 查询 Agent 的任务
public Page<TaskBinding> queryAgentTasks(String agentId, TaskQuery query) {
    return taskBindingMapper.selectPage(
        query.toPage(),
        Wrappers.<TaskBinding>lambdaQuery()
            .eq(TaskBinding::getAgentId, agentId)
            .orderByDesc(TaskBinding::getCreatedTime)
    );
}
```

### 7.2 任务详情

```java
public TaskDetail getTaskDetail(String taskId) {
    TaskBinding binding = taskBindingMapper.selectByTaskId(taskId);

    // 从 OpenFang 获取详细执行轨迹
    TaskRunDetail runDetail = openFangClient.getTaskRunDetail(binding.getTaskRunId());

    return TaskDetail.builder()
        .binding(binding)
        .steps(runDetail.getSteps())
        .toolCalls(runDetail.getToolCalls())
        .approvals(approvalBridge.getApprovals(taskId))
        .build();
}
```
