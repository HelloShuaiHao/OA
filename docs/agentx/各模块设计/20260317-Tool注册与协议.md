### 3.2 注解驱动注册

```java
@Target(ElementType.TYPE)
@Retention(RetentionPolicy.RUNTIME)
public @interface ToolDefinition {
    String name();
    String displayName() default "";
    String description() default "";
    String category() default "GENERAL";
    RiskLevel riskLevel() default RiskLevel.LOW;
    boolean requireApproval() default false;
}

@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface ToolMethod {
    String description() default "";
}

@Target(ElementType.PARAMETER)
@Retention(RetentionPolicy.RUNTIME)
public @interface ToolParam {
    String value();  // 参数名
    String description() default "";
    boolean required() default true;
}
```

**使用示例**：
```java
@Component
@ToolDefinition(
    name = "bpm_approve_leave",
    displayName = "审批请假",
    description = "审批指定的请假申请",
    category = "BPM",
    riskLevel = RiskLevel.HIGH,
    requireApproval = true
)
public class BpmApproveLeaveToolAdapter implements ToolAdapter {

    @Autowired
    private BpmTaskService bpmTaskService;

    @ToolMethod(description = "执行请假审批")
    public ToolResult execute(
        @ToolParam(value = "taskId", description = "任务 ID") Long taskId,
        @ToolParam(value = "approved", description = "是否批准") Boolean approved,
        @ToolParam(value = "reason", description = "审批意见", required = false) String reason
    ) {
        try {
            bpmTaskService.approve(taskId, approved, reason);
            return ToolResult.success("审批成功");
        } catch (Exception e) {
            return ToolResult.error("审批失败: " + e.getMessage());
        }
    }
}
```

### 3.3 自动扫描注册

```java
@Component
public class ToolRegistryScanner implements ApplicationListener<ContextRefreshedEvent> {

    @Autowired
    private ApplicationContext applicationContext;

    @Autowired
    private ToolRegistryMapper toolRegistryMapper;

    @Override
    public void onApplicationEvent(ContextRefreshedEvent event) {
        // 扫描所有带 @ToolDefinition 的 Bean
        Map<String, Object> beans = applicationContext
            .getBeansWithAnnotation(ToolDefinition.class);

        for (Object bean : beans.values()) {
            registerTool(bean);
        }
    }

    private void registerTool(Object bean) {
        Class<?> clazz = bean.getClass();
        ToolDefinition def = clazz.getAnnotation(ToolDefinition.class);

        // 提取 schema
        ToolSchema inputSchema = extractInputSchema(clazz);
        ToolSchema outputSchema = extractOutputSchema(clazz);

        // 保存到数据库
        ToolRegistry registry = new ToolRegistry();
        registry.setToolName(def.name());
        registry.setDisplayName(def.displayName());
        registry.setDescription(def.description());
        registry.setCategory(def.category());
        registry.setRiskLevel(def.riskLevel().name());
        registry.setRequireApproval(def.requireApproval());
        registry.setInputSchema(JSON.toJSONString(inputSchema));
        registry.setOutputSchema(JSON.toJSONString(outputSchema));
        registry.setAdapterClass(clazz.getName());

        toolRegistryMapper.insertOrUpdate(registry);
    }
}
```

## 4. Tool 适配器

### 4.1 适配器接口

```java
public interface ToolAdapter {
    ToolResult execute(Map<String, Object> params);
}

@Data
public class ToolResult {
    private boolean success;
    private Object data;
    private String error;

    public static ToolResult success(Object data) {
        ToolResult result = new ToolResult();
        result.setSuccess(true);
        result.setData(data);
        return result;
    }

    public static ToolResult error(String error) {
        ToolResult result = new ToolResult();
        result.setSuccess(false);
        result.setError(error);
        return result;
    }
}
```

### 4.2 适配器工厂

```java
@Component
public class ToolAdapterFactory {

    @Autowired
    private ApplicationContext applicationContext;

    private final Map<String, ToolAdapter> adapters = new ConcurrentHashMap<>();

    public ToolAdapter getAdapter(String toolName) {
        return adapters.computeIfAbsent(toolName, name -> {
            ToolRegistry registry = toolRegistryMapper.selectByToolName(name);
            if (registry == null) {
                throw new ToolNotFoundException(name);
            }

            try {
                Class<?> clazz = Class.forName(registry.getAdapterClass());
                return (ToolAdapter) applicationContext.getBean(clazz);
            } catch (Exception e) {
                throw new ToolAdapterLoadException(name, e);
            }
        });
    }
}
```

## 5. Tool 调用协议

### 5.1 OA 侧 API

```java
@RestController
@RequestMapping("/api/agentx/tools")
public class ToolController {

    @PostMapping("/{toolName}/invoke")
    public CommonResult<ToolResult> invokeTool(
        @PathVariable String toolName,
        @RequestBody ToolInvokeRequest request
    ) {
        // 1. 权限检查
        checkPermission(request.getAgentId(), toolName);

        // 2. 参数验证
        validateParams(toolName, request.getParams());

        // 3. 审批检查
        if (requiresApproval(toolName, request.getParams())) {
            return handleApprovalRequired(toolName, request);
        }

        // 4. 执行 Tool
        ToolAdapter adapter = toolAdapterFactory.getAdapter(toolName);
        ToolResult result = adapter.execute(request.getParams());

        // 5. 审计日志
        auditService.logToolInvocation(request, result);

        return success(result);
    }
}
```

### 5.2 OpenFang 调用

```rust
// OpenFang 调用 OA Tool
pub async fn call_oa_tool(
    tool_name: &str,
    params: serde_json::Value,
    ctx: &ExecutionContext,
) -> Result<ToolResult, String> {
    let request = ToolInvokeRequest {
        agent_id: ctx.agent_id.clone(),
        task_run_id: ctx.task_run_id.clone(),
        tool_name: tool_name.to_string(),
        params,
    };

    let response = oa_client
        .post(&format!("/api/agentx/tools/{}/invoke", tool_name))
        .json(&request)
        .send()
        .await?;

    if response.status().is_success() {
        Ok(response.json().await?)
    } else {
        Err(format!("Tool call failed: {}", response.status()))
    }
}
```

## 7. 安全控制

### 7.1 参数验证

```java
public void validateParams(String toolName, Map<String, Object> params) {
    ToolRegistry registry = toolRegistryMapper.selectByToolName(toolName);
    ToolSchema schema = JSON.parseObject(registry.getInputSchema(), ToolSchema.class);

    // 检查必填参数
    for (String required : schema.getRequired()) {
        if (!params.containsKey(required)) {
            throw new MissingParameterException(required);
        }
    }

    // 检查参数类型和格式
    for (Map.Entry<String, Object> entry : params.entrySet()) {
        ParameterSchema paramSchema = schema.getProperties().get(entry.getKey());
        if (paramSchema != null) {
            validateParameter(entry.getValue(), paramSchema);
        }
    }
}
```

### 7.2 输出过滤

```java
public ToolResult filterOutput(ToolResult result, ExecutionContext ctx) {
    // 过滤敏感字段
    if (result.getData() instanceof Map) {
        Map<String, Object> data = (Map<String, Object>) result.getData();
        data.remove("password");
        data.remove("token");
        data.remove("secret");
```
