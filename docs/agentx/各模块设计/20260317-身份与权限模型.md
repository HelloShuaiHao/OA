# 身份与权限模型设计

## 1. 核心问题

- Agent 不是普通 OA 用户，如何建模其身份
- Agent 代表用户执行时，权限如何计算
- 多租户场景下的权限隔离
- Tool 调用的细粒度权限控制

## 2. 身份模型

### 2.1 核心对象

**AgentPrincipal（Agent 安全主体）**：
```java
public class AgentPrincipal {
    private Long id;
    private Long tenantId;
    private String agentId;           // 全局唯一
    private String name;
    private AgentType type;           // SYSTEM, DEPARTMENT, PERSONAL
    private PrincipalStatus status;   // ACTIVE, SUSPENDED, DELETED
    private String credentialHash;    // Agent 凭证哈希
    private LocalDateTime createdTime;
}
```

**HumanPrincipal（人类用户）**：
- 复用现有 OA 用户体系
- 不需要新建模型

**DelegationGrant（委托授权）**：
```java
public class DelegationGrant {
    private Long id;
    private Long tenantId;
    private Long userId;              // 委托人
    private String agentId;           // 被委托的 Agent
    private String[] scopes;          // 授权范围：["bpm:read", "bpm:approve:leave"]
    private LocalDateTime expiresAt;  // 过期时间
    private GrantStatus status;       // ACTIVE, REVOKED, EXPIRED
}
```

**ExecutionContext（执行上下文）**：
```java
public class ExecutionContext {
    private String agentId;
    private Long onBehalfOfUserId;    // 代表哪个用户
    private Long tenantId;
    private String[] effectiveScopes; // 实际生效的权限
    private String taskRunId;         // 关联的任务
}
```

### 2.2 Agent 类型

**SYSTEM Agent**：
- 系统级 Agent，不属于特定用户
- 例如：定时报表生成、数据清洗
- 权限：预定义的系统权限

**DEPARTMENT Agent**：
- 部门级 Agent，服务整个部门
- 例如：销售部助手、财务审批助手
- 权限：部门数据范围 + 部门授权的 Tool

**PERSONAL Agent**：
- 个人助手，只服务单个用户
- 例如：个人日程助手、邮件助手
- 权限：用户授权范围

## 3. 权限模型

### 3.1 权限计算公式

```
实际权限 = Agent 基础能力 ∩ 用户委托范围 ∩ 场景策略 ∩ 数据权限
```

**示例**：
- Agent 基础能力：["bpm:*", "crm:read"]
- 用户委托范围：["bpm:approve:leave", "bpm:read"]
- 场景策略：["bpm:approve:leave:amount<=5000"]
- 数据权限：["dept_id=100"]

最终权限：只能审批本部门金额 ≤5000 的请假

### 3.2 权限对象

**Capability（能力）**：
```java
public class Capability {
    private String resource;   // "bpm", "crm", "erp"
    private String action;     // "read", "write", "approve"
    private String scope;      // "leave", "expense", "*"

    // 示例：bpm:approve:leave
    public String toPermissionString() {
        return resource + ":" + action + ":" + scope;
    }
}
```

**ToolPermission（Tool 权限）**：
```sql
CREATE TABLE agentx_tool_permission (

```

**DataScope（数据权限）**：

### 3.3 权限检查流程

```java
public boolean checkPermission(ExecutionContext ctx, String permission, Object resource) {
    // 1. 检查 Agent 基础能力
    if (!agentHasCapability(ctx.getAgentId(), permission)) {
        return false;
    }

    // 2. 检查用户委托范围
    if (ctx.getOnBehalfOfUserId() != null) {
        if (!userDelegated(ctx.getOnBehalfOfUserId(), ctx.getAgentId(), permission)) {
            return false;
        }
    }

    // 3. 检查场景策略
    if (!scenarioPolicyAllows(ctx, permission, resource)) {
        return false;
    }

    // 4. 检查数据权限
    if (!dataAccessAllowed(ctx, resource)) {
        return false;
    }

    return true;
}
```

## 4. 多租户隔离

### 4.1 租户边界

**强制规则**：
- 所有 Agent 必须属于一个租户
- 所有请求必须携带 tenantId
- 跨租户访问直接拒绝

**实现**：
```java
@Aspect
public class TenantIsolationAspect {

    @Before("@annotation(RequireTenant)")
    public void checkTenant(JoinPoint jp) {
        ExecutionContext ctx = getCurrentContext();
        Object resource = getResourceFromArgs(jp.getArgs());

        if (resource.getTenantId() != ctx.getTenantId()) {
            throw new TenantIsolationException("跨租户访问被拒绝");
        }
    }
}
```

### 4.2 租户管理员

**租户管理员权限**：
- 创建/删除 Agent
- 授权 Agent 能力
- 查看审计日志
- 配置租户配额

**超级管理员权限**：
- 管理所有租户
- 系统配置
- 跨租户数据查询（仅用于运维）

### 5.2 Tool 调用检查

```java
public Result invokeTool(ExecutionContext ctx, String toolName, Map<String, Object> params) {
    // 1. 检查 Tool 是否存在
    ToolDescriptor tool = toolRegistry.get(toolName);
    if (tool == null) {
        throw new ToolNotFoundException(toolName);
    }

    // 2. 检查 Agent 是否有权限调用
    ToolPermission perm = getToolPermission(ctx.getTenantId(), ctx.getAgentId(), toolName);
    if (perm == null || !perm.isAllowed()) {
        throw new ToolPermissionDeniedException(toolName);
    }

    // 3. 检查调用频率
    if (exceedsRateLimit(ctx.getAgentId(), toolName, perm.getMaxCallsPerHour())) {
        throw new RateLimitExceededException(toolName);
    }

    // 4. 检查条件
    if (!matchesConditions(params, perm.getConditions())) {
        throw new ToolConditionNotMetException(toolName);
    }

    // 5. 如果需要审批，创建审批请求
    if (perm.isRequireApproval()) {
        return createApprovalRequest(ctx, tool, params);
    }

    // 6. 执行 Tool
    return tool.invoke(params);
}
```
