# 审批桥接设计

## 1. 核心问题

- Agent 执行高风险操作时如何触发审批
- 审批流程在 OA BPM 中如何建模
- 审批结果如何回流到 OpenFang
- 审批超时和拒绝如何处理

## 2. 设计原则

**单一真相源**：
- 审批流程定义：OA BPM
- 审批实例状态：OA BPM
- 审批历史记录：OA BPM
- OpenFang 只发起审批需求和接收结果

**不允许**：
- OpenFang 自己维护审批状态机
- 双边各保一套审批记录
- 绕过 OA 直接执行高风险操作

## 3. 审批绑定模型

### 3.1 数据模型

```sql
CREATE TABLE agentx_approval_binding (
    id BIGINT PRIMARY KEY,
    tenant_id BIGINT NOT NULL,

    agent_id VARCHAR(64) NOT NULL,
    user_id BIGINT NOT NULL COMMENT '发起用户',
    tool_name VARCHAR(128) NOT NULL COMMENT '触发审批的 Tool',
    tool_params JSON COMMENT 'Tool 参数',
    risk_level VARCHAR(16) COMMENT 'LOW, MEDIUM, HIGH, CRITICAL',
    bpm_process_instance_id VARCHAR(64) COMMENT 'BPM 流程实例 ID',
    approval_status VARCHAR(16) NOT NULL COMMENT 'PENDING, APPROVED, REJECTED, TIMEOUT',
    approver_id BIGINT COMMENT '审批人',
    approval_comment TEXT,
    created_time DATETIME NOT NULL,
    approved_time DATETIME,
    INDEX idx_task_run (task_run_id),
    INDEX idx_bpm (bpm_process_instance_id)
);
```

## 4. 审批流程

### 4.1 触发审批

**OpenFang 侧**：
```rust
// Tool 执行前检查
if tool.requires_approval() {
    let approval_req = ApprovalRequest {
        task_run_id: task.id.clone(),
        tool_name: tool.name.clone(),
        tool_params: params.clone(),
        reason: "金额超过自动审批阈值",
    };

    // 调用 OA 审批接口
    let approval_id = oa_client.request_approval(approval_req).await?;

    // 阻塞任务，等待审批结果
    task.block_on_approval(approval_id).await;
}
```

**OA 侧接口**：
```java
@PostMapping("/approval/request")
public CommonResult<ApprovalResponse> requestApproval(@RequestBody ApprovalRequest request) {
    // 1. 创建审批绑定
    ApprovalBinding binding = new ApprovalBinding();
    binding.setTaskRunId(request.getTaskRunId());
    binding.setToolName(request.getToolName());
    binding.setStatus(ApprovalStatus.PENDING);
    approvalBindingMapper.insert(binding);

    // 2. 启动 BPM 流程
    ProcessInstance processInstance = bpmService.startProcess(
        "agent_tool_approval",  // 流程定义 key
        request.getUserId(),
        buildProcessVariables(request)
    );

    // 3. 更新绑定
    binding.setBpmProcessInstanceId(processInstance.getId());
    approvalBindingMapper.updateById(binding);

    return success(ApprovalResponse.builder()
        .approvalId(binding.getId())
        .bpmProcessInstanceId(processInstance.getId())
        .status("pending")
        .build());
}
```

### 4.2 BPM 流程定义

```xml
<process id="agent_tool_approval" name="Agent 工具审批">
  <startEvent id="start"/>

  <userTask id="approve" name="审批">
    <extensionElements>
      <flowable:assignee>${approver}</flowable:assignee>
    </extensionElements>
  </userTask>

  <exclusiveGateway id="decision"/>

  <endEvent id="approved" name="通过"/>
  <endEvent id="rejected" name="拒绝"/>

  <sequenceFlow sourceRef="start" targetRef="approve"/>
  <sequenceFlow sourceRef="approve" targetRef="decision"/>
  <sequenceFlow sourceRef="decision" targetRef="approved">
    <conditionExpression>${approved == true}</conditionExpression>
  </sequenceFlow>
  <sequenceFlow sourceRef="decision" targetRef="rejected">
    <conditionExpression>${approved == false}</conditionExpression>
  </sequenceFlow>
</process>
```

### 4.3 审批结果回调

**BPM 流程结束监听器**：
```java
@Component
public class ApprovalEndListener implements ExecutionListener {

    @Override
    public void notify(DelegateExecution execution) {
        String processInstanceId = execution.getProcessInstanceId();
        Boolean approved = (Boolean) execution.getVariable("approved");
        String comment = (String) execution.getVariable("comment");

        // 查询审批绑定
        ApprovalBinding binding = approvalBindingMapper
            .selectByBpmProcessInstanceId(processInstanceId);

        // 更新状态
        binding.setApprovalStatus(approved ? APPROVED : REJECTED);
        binding.setApprovalComment(comment);
        binding.setApprovedTime(LocalDateTime.now());
        approvalBindingMapper.updateById(binding);

        // 回调 OpenFang
        openFangClient.notifyApprovalResult(
            binding.getTaskRunId(),
            ApprovalResult.builder()
                .approvalId(binding.getId())
                .approved(approved)
                .comment(comment)
                .build()
        );
    }
}
```

## 5. 审批超时处理

### 5.1 超时检测

```java
@Scheduled(fixedDelay = 60000) // 每分钟
public void checkApprovalTimeout() {
    List<ApprovalBinding> pending = approvalBindingMapper
        .selectByStatus(ApprovalStatus.PENDING);

    for (ApprovalBinding binding : pending) {
        Duration elapsed = Duration.between(binding.getCreatedTime(), now());
        if (elapsed.compareTo(binding.getTimeout()) > 0) {
            // 超时处理
            handleTimeout(binding);
        }
    }
}
```

### 5.2 超时策略

**策略 1：自动拒绝**
```java
private void handleTimeout(ApprovalBinding binding) {
    binding.setApprovalStatus(ApprovalStatus.TIMEOUT);
    approvalBindingMapper.updateById(binding);

    // 通知 OpenFang
    openFangClient.notifyApprovalResult(
        binding.getTaskRunId(),
        ApprovalResult.timeout()
    );
}
```

**策略 2：升级审批**
```java
private void handleTimeout(ApprovalBinding binding) {
    // 升级到上级审批
    Long nextApprover = getNextLevelApprover(binding.getApproverId());
    bpmService.reassignTask(binding.getBpmProcessInstanceId(), nextApprover);
}
```

## 6. 审批查询

### 6.1 待审批列表

```java
public Page<ApprovalBinding> getPendingApprovals(Long approverId) {
    // 从 BPM 查询待办任务
    List<Task> tasks = bpmService.getTasksByAssignee(approverId);

    // 关联审批绑定
    List<String> processInstanceIds = tasks.stream()
        .map(Task::getProcessInstanceId)
        .collect(Collectors.toList());

    return approvalBindingMapper.selectByBpmProcessInstanceIds(processInstanceIds);
}
```

### 6.2 审批详情

```java
public ApprovalDetail getApprovalDetail(Long approvalId) {
    ApprovalBinding binding = approvalBindingMapper.selectById(approvalId);

    // 获取 TaskRun 上下文
    TaskRunDetail taskDetail = openFangClient.getTaskRunDetail(binding.getTaskRunId());

    // 获取 BPM 流程信息
    ProcessInstance process = bpmService.getProcessInstance(binding.getBpmProcessInstanceId());

    return ApprovalDetail.builder()
        .binding(binding)
        .taskContext(taskDetail.getContext())
        .toolDescription(getToolDescription(binding.getToolName()))
        .riskAnalysis(analyzeRisk(binding))
        .processHistory(process.getHistory())
        .build();
}
```

## 7. 实施建议

### Phase 1：基础审批
- 单一审批流程
- 同步回调
- 简单超时处理

### Phase 2：复杂流程
- 多级审批
- 会签/或签
- 审批升级

### Phase 3：智能审批
- 风险评分
- 自动审批规则
- 审批建议
