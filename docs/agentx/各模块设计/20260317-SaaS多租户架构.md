## 3. 数据隔离策略

### 3.1 隔离方案对比

**方案 A：独立数据库**
```
租户 A → DB_A
租户 B → DB_B
租户 C → DB_C
```
- 优点：完全隔离，安全性最高
- 缺点：成本高，运维复杂

**方案 B：共享数据库 + 独立 Schema**
```
DB
├─ schema_tenant_a
├─ schema_tenant_b
└─ schema_tenant_c
```
- 优点：隔离性好，成本适中
- 缺点：Schema 数量有限制

**方案 C：共享数据库 + 租户字段**
```
所有表都有 tenant_id 字段
WHERE tenant_id = ?
```
- 优点：成本低，扩展性好
- 缺点：需要严格的代码控制

**推荐方案**：
- 小租户：方案 C（共享数据库）
- 大租户：方案 A（独立数据库）
- 根据租户规模动态选择

@Component
public class TenantInterceptor implements HandlerInterceptor {

    @Override
    public boolean preHandle(HttpServletRequest request,
                            HttpServletResponse response,
                            Object handler) {
        // 从 token 或 header 提取租户 ID
        Long tenantId = extractTenantId(request);
        if (tenantId == null) {
            throw new TenantNotFoundException();
        }

        // 设置到上下文
        TenantContext.setTenantId(tenantId);
        return true;
    }

    @Override
    public void afterCompletion(HttpServletRequest request,
                                HttpServletResponse response,
                                Object handler,
                                Exception ex) {
        TenantContext.clear();
    }
}

## 4. 配额管理

### 4.1 配额检查

```java
@Component
public class QuotaChecker {

    public void checkAgentQuota(Long tenantId) {
        TenantQuota quota = quotaMapper.selectByTenantId(tenantId);
        int currentCount = agentMapper.countByTenantId(tenantId);

        if (currentCount >= quota.getMaxAgents()) {
            throw new QuotaExceededException("Agent 数量已达上限");
        }
    }

    public void checkTaskQuota(Long tenantId) {
        TenantQuota quota = quotaMapper.selectByTenantId(tenantId);
        int runningCount = taskBindingMapper.countRunningByTenantId(tenantId);

        if (runningCount >= quota.getMaxConcurrentTasks()) {
            throw new QuotaExceededException("并发任务数已达上限");
        }
    }

    public void checkToolCallQuota(Long tenantId) {
        TenantQuota quota = quotaMapper.selectByTenantId(tenantId);
        TenantUsage usage = usageMapper.selectByTenantIdAndDate(tenantId, today());

        if (usage.getToolCallCount() >= quota.getMaxToolCallsPerDay()) {
            throw new QuotaExceededException("今日 Tool 调用次数已达上限");
        }
    }
}
```

### 4.2 限流

```java
@Component
public class TenantRateLimiter {

    private final LoadingCache<Long, RateLimiter> limiters = CacheBuilder.newBuilder()
        .expireAfterAccess(1, TimeUnit.HOURS)
        .build(new CacheLoader<Long, RateLimiter>() {
            @Override
            public RateLimiter load(Long tenantId) {
                TenantQuota quota = quotaMapper.selectByTenantId(tenantId);
                double permitsPerSecond = quota.getMaxApiCallsPerMinute() / 60.0;
                return RateLimiter.create(permitsPerSecond);
            }
        });

    public boolean tryAcquire(Long tenantId) {
        try {
            RateLimiter limiter = limiters.get(tenantId);
            return limiter.tryAcquire(1, TimeUnit.SECONDS);
        } catch (Exception e) {
            return false;
        }
    }
}
```

## 5. OpenFang 实例分配

### 5.1 分配策略

```java
public class InstanceAllocator {

    public String allocateInstance(Long tenantId) {
        Tenant tenant = tenantMapper.selectById(tenantId);

        // 策略 1：大租户独立实例
        if (tenant.getScale() == TenantScale.ENTERPRISE) {
            return createDedicatedInstance(tenantId);
        }

        // 策略 2：小租户共享实例
        return findSharedInstance(tenantId);
    }

    private String createDedicatedInstance(Long tenantId) {
        // 调用 K8s API 创建独立 OpenFang Pod
        // 或调用云服务 API 创建独立实例
        String instanceId = k8sClient.createOpenFangPod(tenantId);

        // 注册实例
        OpenFangInstance instance = new OpenFangInstance();
        instance.setTenantId(tenantId);
        instance.setInstanceId(instanceId);
        instance.setEndpoint("http://" + instanceId + ":4201");
        instanceMapper.insert(instance);

        return instanceId;
    }

    private String findSharedInstance(Long tenantId) {
        // 查找负载最低的共享实例
        OpenFangInstance instance = instanceMapper
            .selectSharedInstances()
            .stream()
            .min(Comparator.comparing(OpenFangInstance::getLoadScore))
            .orElseThrow(() -> new NoAvailableInstanceException());

        return instance.getInstanceId();
    }
}
```

### 7.1 计费模型

public class BillingCalculator {

    public BigDecimal calculateMonthlyCost(Long tenantId, YearMonth month) {
        TenantUsage usage = usageMapper.selectByTenantIdAndMonth(tenantId, month);

        BigDecimal baseCost = getBaseCost(tenantId);
        BigDecimal taskCost = usage.getTaskCount() * TASK_UNIT_PRICE;
        BigDecimal toolCallCost = usage.getToolCallCount() * TOOL_CALL_UNIT_PRICE;
        BigDecimal storageCost = usage.getStorageUsedMb() * STORAGE_UNIT_PRICE;
        BigDecimal modelCost = usage.getModelTokenCount() * MODEL_TOKEN_UNIT_PRICE;

        return baseCost.add(taskCost).add(toolCallCost).add(storageCost).add(modelCost);
    }
}
