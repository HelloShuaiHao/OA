## 3. 上下文提供者

### 3.1 提供者接口

```java
public interface ContextProvider {
    String getName();
    boolean supports(String businessType);
    Map<String, Object> provide(ContextRequest request);
}

@Data
public class ContextRequest {
    private Long userId;
    private String businessType;
    private String businessId;
    private String[] requiredFields;
}
```

### 3.2 用户上下文提供者

```java
@Component
public class UserContextProvider implements ContextProvider {

    @Autowired
    private AdminUserService userService;

    @Autowired
    private PermissionService permissionService;

    @Override
    public String getName() {
        return "user";
    }

    @Override
    public boolean supports(String businessType) {
        return true; // 所有业务类型都需要用户上下文
    }

    @Override
    public Map<String, Object> provide(ContextRequest request) {
        AdminUserDO user = userService.getUser(request.getUserId());
        List<String> permissions = permissionService.getUserPermissions(request.getUserId());

        UserContext ctx = new UserContext();
        ctx.setUserId(user.getId());
        ctx.setUsername(user.getUsername());
        ctx.setNickname(user.getNickname());
        ctx.setDeptId(user.getDeptId());
        ctx.setPermissions(permissions);

        return Map.of("user", ctx);
    }
}
```

### 3.3 BPM 上下文提供者

```java
@Component
public class BpmContextProvider implements ContextProvider {

    @Autowired
    private BpmTaskService bpmTaskService;

    @Override
    public String getName() {
        return "bpm";
    }

    @Override
    public boolean supports(String businessType) {
        return businessType.startsWith("BPM_") ||
               List.of("LEAVE", "EXPENSE").contains(businessType);
    }

    @Override
    public Map<String, Object> provide(ContextRequest request) {
        // 查询用户的待办任务
        List<Task> pendingTasks = bpmTaskService.getTasksByAssignee(request.getUserId());

        // 如果有具体业务 ID，查询详情
        Map<String, Object> businessDetail = null;
        if (request.getBusinessId() != null) {
            businessDetail = bpmTaskService.getProcessVariables(request.getBusinessId());
        }

        return Map.of(
            "pending_tasks", pendingTasks,
            "business_detail", businessDetail
        );
    }
}
```

## 4. 上下文组装器

### 4.1 组装器实现

```java
@Component
public class ContextAssembler {

    @Autowired
    private List<ContextProvider> providers;

    public BusinessContext assemble(ContextRequest request) {
        BusinessContext context = new BusinessContext();

        // 并行调用所有支持的提供者
        List<CompletableFuture<Map<String, Object>>> futures = providers.stream()
            .filter(p -> p.supports(request.getBusinessType()))
            .map(p -> CompletableFuture.supplyAsync(() -> {
                try {
                    return p.provide(request);
                } catch (Exception e) {
                    log.error("Context provider {} failed", p.getName(), e);
                    return Map.of();
                }
            }))
            .collect(Collectors.toList());

        // 等待所有提供者完成
        CompletableFuture.allOf(futures.toArray(new CompletableFuture[0])).join();

        // 合并结果
        Map<String, Object> merged = new HashMap<>();
        for (CompletableFuture<Map<String, Object>> future : futures) {
            merged.putAll(future.join());
        }

        // 填充到 BusinessContext
        context.setUser((UserContext) merged.get("user"));
        context.setOrg((OrgContext) merged.get("org"));
        context.setTask((TaskContext) merged.get("task"));
        context.setBusinessData((BusinessData) merged.get("business_data"));

        return context;
    }
}
```

## 5. 场景化上下文

### 5.1 请假场景

```java
@Component
public class LeaveContextProvider implements ContextProvider {

    @Override
    public String getName() {
        return "leave";
    }

    @Override
    public boolean supports(String businessType) {
        return "LEAVE".equals(businessType);
    }

    @Override
    public Map<String, Object> provide(ContextRequest request) {
        // 查询请假政策
        LeavePolicy policy = leavePolicyService.getPolicy(request.getUserId());

        // 查询用户剩余假期
        LeaveBalance balance = leaveBalanceService.getBalance(request.getUserId());

        // 查询历史请假记录
        List<LeaveRecord> history = leaveRecordService.getRecentRecords(
            request.getUserId(),
            LocalDate.now().minusMonths(6)
        );

        return Map.of(
            "leave_policy", policy,
            "leave_balance", balance,
            "leave_history", history
        );
    }
}
```

}

## 6. 上下文缓存

### 6.1 缓存策略

```java
@Component
public class ContextCache {

    private final LoadingCache<String, BusinessContext> cache = CacheBuilder.newBuilder()
        .expireAfterWrite(5, TimeUnit.MINUTES)
        .maximumSize(1000)
        .build(new CacheLoader<String, BusinessContext>() {
            @Override
            public BusinessContext load(String key) {
                return assembleContext(parseKey(key));
            }
        });

    public BusinessContext get(ContextRequest request) {
        String key = buildKey(request);
        try {
            return cache.get(key);
        } catch (Exception e) {
            return assembleContext(request);
        }
    }

    private String buildKey(ContextRequest request) {
        return String.format("%d:%s:%s",
            request.getUserId(),
            request.getBusinessType(),
            request.getBusinessId()
        );
    }
}
```

## 7. 上下文传递

### 7.1 传递给 OpenFang

```java
public TaskRunResponse createTaskRun(TaskRequest request) {
    // 组装上下文
    BusinessContext context = contextAssembler.assemble(
        ContextRequest.builder()
            .userId(request.getUserId())
            .businessType(request.getBusinessType())
            .businessId(request.getBusinessId())
            .build()
    );

    // 调用 OpenFang
    return openFangClient.createTaskRun(
        request.getAgentId(),
        request.getInstruction(),
        context
    );
}
```
