### 2. 启动 OA 系统


### 3. 准备测试数据
- 创建测试用户
- 配置审批流程

## 测试步骤

### Step 1: 创建请假申请助手

在 OpenFang 项目创建 agent 配置文件：
```bash
mkdir -p /Users/mbp/Desktop/OF/dev-sh/agents/oa-leave-applicant
```

创建 `agent.toml`（见下一步）

### Step 2: 创建审批助手

```bash
mkdir -p /Users/mbp/Desktop/OF/dev-sh/agents/oa-approval-assistant
```

创建 `agent.toml`（见下一步）

### Step 3: 测试请假申请

```bash
openfang chat oa-leave-applicant
> "我下周一到周三要请假，家里有事"
```

观察：
- Agent 是否正确解析时间
- 是否调用 OA 接口
- 返回结果是否正确

### Step 4: 测试审批

```bash
openfang chat oa-approval-assistant
> "我有哪些待审批的？"
```

观察：
- 是否正确查询待办
- 展示格式是否清晰

### Step 5: 多租户测试

通过 OA API 为不同租户创建 agent 实例，验证隔离性。
