# 请假申请助手测试

## Agent 配置

在 OpenFang 创建 `oa-leave-applicant` agent。

## 测试用例

### 用例 1: 创建请假申请

**输入**：
```
"我下周一到周三要请假，家里有事"
```

**期望行为**：
1. Agent 解析时间：2026-03-17 至 2026-03-19
2. 询问请假类型（病假/事假/婚假）
3. 调用 `POST /bpm/oa/leave/create`
4. 返回请假单号

**验证点**：
- 时间解析正确
- 接口调用成功
- 返回结果清晰

### 用例 2: 查询请假记录

**输入**：
```
"我有哪些请假记录？"
```

**期望行为**：
1. 调用 `GET /bpm/oa/leave/page`
2. 展示请假列表（时间、天数、状态）

### 用例 3: 信息不完整

**输入**：
```
"我要请假"
```

**期望行为**：
1. 询问开始时间
2. 询问结束时间
3. 询问原因
