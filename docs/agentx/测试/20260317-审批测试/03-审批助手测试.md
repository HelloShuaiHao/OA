# 审批助手测试

## Agent 配置

在 OpenFang 创建 `oa-approval-assistant` agent。

## 测试用例

### 用例 1: 查询待办

**输入**：
```
"我有哪些待审批的？"
```

**期望行为**：
1. 调用 `GET /bpm/task/todo-page`
2. 展示待办列表：
   - 申请人
   - 请假时间
   - 天数
   - 原因

### 用例 2: 审批通过

**输入**：
```
"通过张三的请假"
```

**期望行为**：
1. 从待办列表中找到张三的任务
2. 调用 `POST /bpm/task/approve`
3. 返回审批结果

### 用例 3: 审批拒绝

**输入**：
```
"拒绝李四的请假，理由是需要提供病假条"
```

**期望行为**：
1. 调用 `POST /bpm/task/reject`
2. 传递拒绝理由
3. 返回审批结果
